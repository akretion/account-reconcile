To use this module, you need to:

#. Go to *Accounting > Accounting > Import Batch File*.
#. Select the Stripe journal: no file is needed. *Import From* shows the
   date from which the payouts are imported. Before the first import of
   the journal, *First Import From* sets the arrival date of the first
   payout to import; leave it empty to import all the payouts.
#. Click on *Import*: one journal entry is created per Stripe payout
   paid since that date and not imported yet.
